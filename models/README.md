# Models

Detailed meshes for the Performance Benchmark demo, by Keenan Crane, from his
3D model repository: https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/

| File | Source | Triangles | License |
|---|---|---|---|
| `ogre.obj` | "Jerry the Ogre", `ogre.zip` / `bs_rest.obj` | 39,856 | Public domain |
| `blub.obj` | "Blub", `blub.zip` / `blub_triangulated.obj` | 14,208 | Public domain |

Both archives' READMEs state: "As the sole author of this data, I hereby
release it into the public domain." The repository page lists them as
CC0 1.0 Universal.

Both files are reduced to vertex positions and faces (`v` / `f` lines); normals
and texture coordinates were dropped because the engine shades by face
normals. The ogre's back of the head is open in the original data.
